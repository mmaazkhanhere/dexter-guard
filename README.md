# Dexter Guard

The repository contains the synthetic German nursing-documentation reliability
engine. Spec 009 adds a React/Vite frontend, a composed FastAPI entrypoint, and
one-URL Vercel configuration. See
[`specs/009-ui-implementation/quickstart.md`](specs/009-ui-implementation/quickstart.md)
for setup, tests, and deployment gates.
